# Digital Twin of an Industrial Furnace
This project implements a digital twin of an industrial furnace using Unity and machine learning. It simulates the furnace operation and visualizes temperature distribution and flow behavior across its different sections.

An MLP (Multilayer Perceptron) model predicts temperature and flow-related parameters based on user-defined inputs. Users can interactively adjust temperature and flow rate within specified ranges and observe how these changes affect the furnace's behavior in real time.

The digital twin integrates machine learning predictions with 3D visualization to provide an interactive representation of the furnace, enabling users to monitor temperature variations, visualize the process, and explore the impact of different operating conditions.
